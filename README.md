# 📅 Agendador de Postagens no Instagram

Um aplicativo em **Python + Tkinter** que permite **agendar postagens de imagens no Instagram automaticamente**, usando a biblioteca [instagrapi](https://github.com/adw0rd/instagrapi).

---

## ✨ Funcionalidades

- Login automático com salvamento de credenciais.  
- Seleção de **pasta de imagens** para postagem.  
- Definição de **legenda única** para todas as imagens.  
- Agendamento por **data inicial** e múltiplos **horários (HH:MM)**.  
- Log de resultados (`post_log.txt`) com sucesso ou falha em cada postagem.  
- Interface gráfica amigável feita com **Tkinter**.
